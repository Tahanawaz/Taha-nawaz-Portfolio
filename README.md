# Taha Nawaz — Developer Portfolio

Personal portfolio for Taha Nawaz, a Software Engineering student and
full-stack developer based in Lahore, Pakistan. It presents selected projects,
technical skills, internship experience, education, and contact channels.

## Stack

- Next.js with the App Router
- React and TypeScript
- Tailwind CSS
- Framer Motion
- Lucide icons
- Canvas-based animated background

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Project structure

- `src/app` — page shell, metadata, sitemap, robots, and global styles
- `src/components` — portfolio sections and interactive UI
- `public/images` — profile and portfolio media
